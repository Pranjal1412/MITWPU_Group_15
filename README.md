Runnr

Problem Statement: Running often feels monotonous and lacks the spark of motivation and engagement. Many users struggle to stay consistent because the experience becomes repetitive and uninteresting over time.

💡Solution
This application enhances the running experience by combining tracking, social interaction, and gamification to keep users engaged and motivated.

Features
📊 Analytics & Progress Tracking
Track distance, time, pace, and performance trends
Visual insights to monitor improvement over time

🎯 Personalised Guidance
Smart suggestions based on user activity
Helps improve consistency and performance

👥 Running Communities
Connect with other runners
Share activities and stay socially motivated

🎮 Gamified Competitive Running
Turn running into a competitive experience
Participate in challenges and compete with friends

🪙 Point System
Earn points based on: Distance covered, Elevation gained, Pace maintained
Additional points for completing challenges
Encourages consistency and performance improvement

🛠️ Tech Stack
Frontend: Swift (iOS Development)
Backend: Supabase
Database: PostgreSQL
